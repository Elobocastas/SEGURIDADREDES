## 📂 Estructura del Repositorio

Este repositorio funciona como mi bóveda personal de conocimientos y *write-ups* (reportes de solución) para los retos de **Capture The Flag (CTF)** de la clase. La documentación está organizada para ser clara, reproducible y servir como referencia rápida en el uso de la terminal de Linux y herramientas de seguridad.

### 📝 Plantilla de Documentación

Cada reto documentado en este repositorio se estructura de la siguiente manera:

> **🚩 [Nombre del Reto]**
> * **Descripción:** *¿Cuál es el objetivo principal del reto o la vulnerabilidad a explotar?*
> * **Solución:** *Paso a paso detallado, incluyendo los comandos ejecutados, scripts utilizados y la lógica para conseguir la bandera.*
> * **Notas adicionales:** *Conceptos clave aprendidos, atajos útiles o errores comunes a evitar.*
> * **Referencias:** *Enlaces a documentación, artículos o manuales externos.*
