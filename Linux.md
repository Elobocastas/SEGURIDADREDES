# Actividad 08 - Configurar entorno de pruebas

> [!info] Datos del Alumno
> **Alumno:** Carlos Castañeda Ramírez
> **Entorno de pruebas elegido:** Entorno virtualizado (Máquina Virtual)

## Descripción del proceso de instalación

Para establecer mi entorno de pruebas, opté por la virtualización de Kali Linux. El proceso que seguí para su configuración fue el siguiente:

1. **Descarga de la imagen:** Ingresé a la página oficial de Kali Linux (kali.org) y descargué la imagen oficial preconstruida para máquinas virtuales, seleccionando la versión de 64-bit.
2. **Configuración del hipervisor:** Utilicé mi software de virtualización e importé el archivo de la máquina virtual previamente descargado.
3. **Asignación de recursos:** Ingresé a los ajustes de la máquina virtual para configurar los recursos de hardware (asignando memoria RAM y núcleos de procesador suficientes para un rendimiento fluido).
4. **Configuración de red:** Verifiqué que el adaptador de red estuviera correctamente configurado para garantizar que el entorno tuviera salida a internet y conexión para las pruebas.
5. **Arranque inicial y actualización:** Inicié la máquina virtual, ingresé al sistema y ejecuté en la terminal los comandos de actualización para dejar el entorno completamente funcional:
